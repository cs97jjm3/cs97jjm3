# James Murrell

**Business Analyst | Tool Builder | Learning by building with AI**

I'm a 59-year-old Business Analyst at The Access Group, working on healthcare software. About 18 months ago I started building my own tools with AI. Since then I've built around 15 automation workflows and a suite of MCP servers that colleagues now use, plus a run of weekend projects for the house and the family. I wrote up how I work in a guide on Gumroad.

I'm not a developer. My BA skills are what make this work: knowing what to build, breaking it into small steps, making the calls and testing everything properly. The AI writes most of the code. I learn something new every time.

## Home Projects

Weekend builds for the house and the family. All built with Claude, one step at a time, and all running on old kit: a Windows PC that was gathering dust and a Raspberry Pi 2.

**🏠 Moby's Home**  
One page for the whole house: Alexa lights and plugs, Echos, the Samsung TV and EE TV box, Chromecasts, PS5 and Xbox, who's home, the computers and the weather. Day, Night and Colour looks, and it works out what's on the EE box even though the box won't say. [Live demo](https://cs97jjm3.github.io/mobys-home/) · [Repository](https://github.com/cs97jjm3/mobys-home)

**🔥 Moby's Heat**  
A dashboard for our ESi Centro thermostat, with boost buttons, charts and an AI warm-up plan worked out from the forecast. Gemini first, Claude as backup, plain rules if both are down. [Repository](https://github.com/cs97jjm3/mobys-heat)

A live F1 pit wall for race weekends with my son Ed: track map, timing, team radio, stewards' decisions and a podium predictions game. The family can watch along from anywhere. [Live demo](https://edsf1.jmmcp.uk) · [Repository](https://github.com/cs97jjm3/race-weekend-dashboard)

**📡 Who's Home**  
A home network watcher for the Pi and a BT Smart Hub 2. Gives every device a proper name and tells my phone when something new joins the Wi-Fi. [Repository](https://github.com/cs97jjm3/homewatch)

**🚗 Ed's Driving Theory Test**

## How I Build

**What I use:**
- Claude (Claude Desktop, MCP and Claude Code) as my building partner
- Node.js and TypeScript for the MCP servers
- Python for the home projects
- SQLite for local storage
- Playwright and Puppeteer for browser work
- Azure DevOps API, n8n, and UK government APIs (GOV.UK, CQC and others)
- Cloudflare (free plan) to put home projects on my own web address, and GitHub Pages for demos

**What I avoid:**
- Big frameworks: mostly plain JavaScript and plain Python
- Paid cloud hosting: everything runs locally or on old kit at home
- OAuth where something simpler will do

**Kit:** Windows 11, VS Code, Git Bash, an old Windows PC as a home server, and a Raspberry Pi 2.
